# Familienhub

Self-hosted family hub: shared calendar, tasks, shopping list, meal plan and reminders, with a web app and Android/iOS apps. This add-on runs the Familienhub server and the web app on your Home Assistant.

- Data stays in the add-on (`/data`, SQLite) and is part of Home Assistant backups.
- Open the web app at `http://<home-assistant>:8000` or from the add-on's **Open web UI** button.
- Optional connections to Home Assistant, Nextcloud, Paperless and others are configured inside Familienhub.

See the **Documentation** tab for setup, options and security notes. Project: <https://github.com/Brottuetchen/familienhub>
